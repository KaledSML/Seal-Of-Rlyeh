Este espacio custodia un artefacto funcional que combina criptografía robusta (AES/Fernet con sales únicas), manipulación del sistema de archivos y mecánicas de protección inspiradas en el horror cósmico para proteger tus carpetas más preciadas de miradas indiscretas.

---

### 🔮 Características del Ritual

* **Cifrado Arcano (`vault.py`):** Empaqueta y cifra tu carpeta de forma segura usando una contraseña maestra.
* **Protocolo de Pánico (`chaos.py` + `grimoire.py`):** Si fallas tres intentos de desbloqueo, el cofre entra en cuarentena (se muda sigilosamente a tus Documentos) y te envía una alerta por correo electrónico adjuntando una pista visual con los glifos de Nug-Soth.
* **Alfabeto Vectorial (`grimoire.py`):** Renderiza imágenes personalizadas con los glifos originales basados en la tradición primigenia.

---

### 📜 Comandos Disponibles

Asegúrate de tener las dependencias instaladas (`cryptography` y `Pillow`) y ejecuta los rituales desde tu terminal:

1. **Configurar y cifrar una carpeta:**
   ```bash
   python seal.py setup
   ```
2. **Intentar abrir el cofre (tienes 3 intentos antes de que actúe el pánico):**
   ```bash
   python seal.py unlock
   ```
3. **Ver el estado actual del cofre:**
   ```bash
   python seal.py status
   ```
